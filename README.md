# CarpiTech

Agente flotante instalable (PWA). Se configura solo desde `skill.json`.

## Publicar en GitHub Pages
1. Creá un repositorio en GitHub llamado `agenteflotantecarpi` y subí **el contenido** de esta carpeta (que `index.html` quede en la raíz).
2. En el repo: Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)` → Save.
3. Esperá un minuto y abrí la URL que te muestra (https://USUARIO.github.io/REPO/).

## Instalar
- **Android / Chrome / Edge (PC):** botón «📲 Instalar» de la ventana, o menú ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartir ⬆️ → *Agregar a pantalla de inicio*.

## Cambiar cosas
Editá `skill.json` (textos, colores, preguntas, proveedor de IA, modo de voz) y volvé a subirlo.
Si cambiás el ícono, reemplazá `assets/mascota.png`, `assets/icon-192.png` y `assets/icon-512.png`.
